# Olho de Deus - IA Hacker (Mascote Tanjiro)

Este projeto contém o código completo da IA "Olho de Deus", com interface gráfica hacker feita em Kivy, mascote interativo Tanjiro Kamado e mapa global em estilo radar.

## Como compilar o APK:
Execute o comando abaixo na pasta do projeto:
`buildozer -v android debug`
